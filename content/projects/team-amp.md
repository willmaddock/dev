From **August through December 2024**, I served as **Technical Lead** for the **Auraria Mobile Parking (AMP)** project, a six-person Kotlin Android application developed for MSU Denver's CS 4360 course.

The project explored how a mobile application could help students, employees, and visitors find parking information, understand cost and availability, review weather and event conditions, and access support features from one interface.

## Project Highlights

- Led technical coordination for a six-person team.
- Developed the application in **Kotlin** and **Android Studio**.
- Managed source integration through Git and task coordination through ClickUp.
- Integrated mapping, weather, event, Firebase, and AI-assisted support capabilities documented by the project.
- Reviewed and merged team contributions.
- Coordinated emulator and physical-device testing.
- Helped prepare technical documentation and the final presentation.
- Applied Agile and Feature-Driven Development practices.

## Application Features

The project documentation describes features including:

1. Parking availability and lot information
2. Filtering by cost, proximity, or availability
3. User reviews
4. AI-assisted directions and support
5. Parking-budget estimates
6. Multi-language access
7. Weather information
8. Event-awareness features for nearby congestion
