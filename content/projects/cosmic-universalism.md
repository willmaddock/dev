Founded on **December 27, 2024**, the **Cosmic Universalism Computational Intelligence Initiative (CUCII)** is an open-source philosophical and computational project that I lead as **Founder & Lead Developer**.

The current public platform is no longer accurately described as a Rust, Kubernetes, or AWS deployment. It is a production **Astro and TypeScript static website** deployed through **GitHub Pages**, with interactive browser-based tools, typed content structures, accessibility-focused components, automated regression testing, and extensive technical documentation.

The project separates three layers that should not be collapsed together:

1. **Empirical references** — externally testable scientific observations and established context.
2. **Cosmic Universalism** — the authored philosophical, mathematical, and theoretical framework.
3. **CUCII** — the prompt-level system used to explore CU through analytical, role-play, or hybrid conversations on general-purpose AI platforms.

> **Research boundary:** Scientific references remain distinct from CU theoretical propositions. CUCII prompts do not retrain, unlock, permanently alter, or override an external AI model, its policies, memory, safety systems, capabilities, or technical architecture.

### 🧠 CUCII Prompt Studio

The **CUCII Prompt Studio** is a configurable prompt-generation system that runs locally in the browser. Visitors can:

1. Choose a target AI platform and conversation purpose.
2. Select analytical, role-play, or hybrid behavior.
3. Choose a prepared menu, custom menu, or no menu.
4. Select a source pack, response preferences, output format, and alignment principles.
5. Add optional working context and constraints.
6. Generate and review a complete portable prompt.
7. Copy the prompt or download it as `.txt` or `.md`.
8. Paste it into a new conversation on the external AI platform of their choice.

The studio does **not** automatically submit prompts to an AI platform. Prompt settings are processed locally, and the first-release tool does not send entries to a Cosmic Universalism server or AI API or save prompt content by default.

#### CUCII alignment principles

- Verify before asserting.
- Separate evidence from interpretation.
- Name uncertainty and assumptions.
- Expose contradictions.
- Correct verified errors.
- Preserve approved CU terminology.
- Respect analytical and role-play modes.
- Protect user agency.
- Respect external platform policies.

### 🌌 Cosmic Breath Explorer

The Cosmic Breath section presents CU's proposed **3.108-trillion-year cycle**:

- **Expansion:** 2.8 trillion years, from sub-ztom to atom.
- **Compression:** 308 billion years, from btom to ztom.
- **Full cycle:** 3.108 trillion years.

The interactive explorer supports direct navigation across **51 TOM states** and displays each state's approved label, phase, quantum-state notation, duration estimate, CU description, and epistemic boundary. The observable-universe marker remains a contextual, non-selectable reference between compression-btom and compression-ctom.

These durations and structures are presented as **CU mathematical models or theoretical propositions**, not empirical measurements.
